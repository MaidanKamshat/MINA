# MINA v2.9.1 — fix: voice calendar duration

Это маленький patch для уже работающей MINA v2.9; это **не** вся папка приложения. Патч не меняет Google OAuth, Google Calendar API, Streamlit UI, списки покупок или `local_data`.

## Почему v2.9 не работала

При разборе `10 a.m. for 15 minutes` промежуточное время окончания `10:15` (без AM/PM) передавалось в `clock_12()` → `mina_saved_places.parse_clock()`. В установленной версии вспомогательный парсер может требовать двенадцатичасовой формат со суффиксом `AM`/`PM`. Он возвращал ошибку; обработчик безопасно отклонял заявку и выдавал `needs_clarification`. При воспроизведении с таким парсером получили **те же 6 failures + 4 errors из 11**, что и на скриншоте с Mac.

**Исправление:** вычисленное время теперь форматируется напрямую из целого количества минут в виде `10:15 AM`, `4:15 PM` или `12:10 PM`, без вызова `clock_12()` для промежуточной 24-часовой строки.

## Установка поверх v2.9

Остановить Streamlit `Control + C`; в Terminal:

```bash
cd ~/Desktop/CMU/labs/capstone/MINA_Day1_baseline
source .venv/bin/activate
cp mina_calendar_v27.py mina_calendar_v27_backup_v29.py
unzip -o ~/Downloads/MINA_v2_9_1_Voice_Calendar_Hotfix.zip -d .
python -m unittest -v test_mina_calendar_v27.py test_mina_voice_calendar_v29.py test_mina_voice_calendar_v291.py
python -m streamlit run streamlit_app.py
```

Ожидаемый результат тестов: `Ran 63 tests`, `OK` при наличии стандартных модулей проекта. Не продолжай голосовую проверку, если тесты упали — сохрани последние строки ошибок. Не выполняй повторно старую команду для v2.9 после установки v2.9.1.

Важное ограничение: локальные проверки выполнялись с заменителями двух недоступных базовых модулей (`mina_saved_places`, `mina_auto_mode`), в т.ч. с **строгим** вариантом парсера часов, воспроизводящим ошибки на Mac. Фактическая интеграция с Mac и микрофоном требует проверки на устройстве.

## Проверка

В MINA сначала **напечатай** исходную фразу, чтобы отделить парсер от ошибки голосовой транскрипции:

`Mina, schedule a test appointment on Monday, November 30th at 10 a.m. for 15 minutes. Remind me one day and two hours before.`

Должен появиться Preview: `Test appointment`, `2026-11-30`, `10:00 AM`–`10:15 AM`, напоминания за один день и два часа. **Не подтверждай запись.** Нажми Cancel. Затем протестируй эту же команду через микрофон.

Если печатная команда проходит, а голосовая нет, причина уже не в расчёте времени — нужно посмотреть точный текст распознанной речи, который MINA показывает перед ответом.
